المجلس الأعلى للطفولة
=====================

محتويات الحزمة:
- index.html: الصفحة الرئيسية (تتضمن مجسم شعار تفاعلي ثلاثي الأبعاد 3D)
- reunion.html: تبويب لم شمل الليبيين (مشغل صوتي مدمج لتشغيل مقطع الأغنية مباشرة بدون صفحات خارجية)
- about.html: الرؤية والرسالة والأهداف
- documentary.html: سرد الفيلم الوثائقي الكامل مع القراءة الصوتية
- gallery.html: معرض الصور والملفات البصرية
- archive.html: سجل الأرشيف ومتابعة المراسلات
- contact.html: نموذج إعداد المذكرات والطباعة
- assets/audio/: ضع ملف أغنية لم الشمل باسم lam-al-shaml.mp3 داخل هذا المجلد ليشتغل تلقائياً في تبويب لم شمل الليبيين

طريقة الرفع على Cloudflare Pages أو Vercel:
1. فك ضغط الملف المضغوط.
2. ارفع مجلد (المجلس الأعلى للطفولة) مباشرة إلى Cloudflare Pages (Upload Assets) أو Vercel.
3. سيفتح الرابط مباشرة لأي زائر دون طلب تسجيل دخول أو جيميل.
